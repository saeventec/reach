# Markdown

## What it is

Markdown is a simple way to format text using plain characters. `#` makes a heading, `**bold**` makes bold text. GitHub and VS Code show it nicely formatted, but it stays readable as plain text. Markdown files end with `.md`.

## Why we use it

All Reach docs are Markdown: easy to write, easy to review in git, and readable everywhere.

## Tiny example

```markdown
# Big heading
## Smaller heading

Some **bold** and *italic* text, and a [link](https://example.com).

- a list item
- another item

`inline code`, and a table:

| Tool | Purpose |
| --- | --- |
| Git | history |
```

Tip: in VS Code, press `Cmd+Shift+V` (Mac) or `Ctrl+Shift+V` (Windows) to preview a Markdown file.

## Alternatives

- **AsciiDoc:** more features, less common.
- **reStructuredText:** used mostly in the Python world.
