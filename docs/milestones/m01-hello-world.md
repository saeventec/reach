# Milestone 1: Hello world end to end

- **Status:** Done (2026-10-31). First green CI run: https://github.com/saeventec/reach/actions/runs/41200313293

## Goal

A React page asks a Go service for a greeting through the Caddy gateway. The service reads it from Postgres. Everything starts with `task dev` in Docker Compose.

```
Browser (React) → Caddy → Go service → Postgres
```

## Steps

Each step is one small commit that runs, reviewed by the owner before the next one starts.

- [x] 1. The `hello` Go service with a `/healthz` endpoint and a test (runs with `go run`)
- [x] 2. A Dockerfile, `compose.yaml` and `task dev`; graceful shutdown
- [x] 3. Postgres in Compose, with a first goose migration (the `greetings` table)
- [x] 4. A first Protobuf definition, Go code generated by buf, and a `GetGreeting` call that reads from Postgres with pgx
- [x] 5. The React + TypeScript + Vite web app, styled with Tailwind CSS, with TypeScript code generated by buf, that calls `GetGreeting`
- [x] 6. Caddy as the gateway in front of the web app and the service
- [x] 7. Linting and formatting (golangci-lint with gofmt, Oxlint, Prettier, buf), run before each commit by Lefthook
- [x] 8. CI on GitHub Actions: lint, test, build
