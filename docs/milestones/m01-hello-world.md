# Milestone 1: Hello world end to end

- **Status:** In progress

## Goal

A React page asks a Go service for a greeting through the Caddy gateway. The service reads it from Postgres. Everything starts with `task dev` in Docker Compose.

```
Browser (React) → Caddy → Go service → Postgres
```

## Steps

Each step is one small commit that runs, reviewed by the owner before the next one starts.

- [x] 1. The `hello` Go service with a `/healthz` endpoint and a test (runs with `go run`)
- [ ] 2. A Dockerfile, `compose.yaml` and `task dev`; graceful shutdown
- [ ] 3. Postgres in Compose, with a first goose migration (the `greetings` table)
- [ ] 4. A first Protobuf definition, Go and TypeScript code generated by buf, and a `GetGreeting` call that reads from Postgres with pgx
- [ ] 5. The React + TypeScript + Vite web app, styled with Tailwind CSS, that calls `GetGreeting`
- [ ] 6. Caddy as the gateway in front of the web app and the service
- [ ] 7. Linting and formatting (gofmt, golangci-lint, Prettier, ESLint), run before each commit by Lefthook
- [ ] 8. CI on GitHub Actions: lint, test, build

## Concepts to learn

Frontend, backend, APIs, containers, databases, migrations, code generation, CI.

## Done when

`task dev` starts everything, the page shows a greeting read from Postgres, and tests and CI pass.
