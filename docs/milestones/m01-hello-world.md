# Milestone 1: Hello world end to end

- **Status:** Planned

## Goal

A React page asks a Go service for a greeting through the Caddy gateway. The service reads it from Postgres. Everything starts with `task dev` in Docker Compose.

```
Browser (React) → Caddy → Go service → Postgres
```

## Steps (draft, to be refined when the milestone starts)

- [ ] A tiny Go service with a `/healthz` endpoint, its own Dockerfile, and a test
- [ ] `compose.yaml` that starts the service, plus a `task dev` command
- [ ] Postgres in Compose, with a first goose migration
- [ ] A first Protobuf definition, with Go and TypeScript code generated by buf
- [ ] The React + TypeScript + Vite web app that calls the service
- [ ] Caddy as the gateway in front of the web app and the service
- [ ] Linting and formatting (gofmt, golangci-lint, Prettier, ESLint)
- [ ] CI on GitHub Actions: lint, test, build

## Open questions for the start of the milestone

- Which first service to build (probably a small part of `auth` or `chat`)
- sqlc and pgx for database access (see "Additional tech to consider" in the brief)
- CSS Modules or Tailwind for styling
- Lefthook for checks before each commit

## Concepts to learn

Frontend, backend, APIs, containers, databases, migrations, code generation, CI.

## Done when

`task dev` starts everything, the page shows a greeting read from Postgres, and tests and CI pass.
