# Milestones

One file per milestone: the goal, the steps, the status, and what was learned. The full list of milestones is in the [project brief](../PROJECT_BRIEF.md#milestones).

## How to add one

1. Copy `_template.md`.
2. Name it with the number and a short title: `m02-accounts.md`.
3. Write the plan when the milestone starts. Tick steps off as they are done.
