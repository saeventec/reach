# Session: Milestone 1, hello world end to end

- **Date:** 2026-10-31
- **Milestone:** m01

## Goal

Build milestone 1: a React page that shows a greeting read from Postgres, through the Caddy gateway, all started with `task dev`, with tests, linting and CI.

## What was done

- Planned the milestone in 8 steps and built them one by one, each reviewed by the owner:
  1. The `hello` Go service with `/healthz` and tests.
  2. Dockerfile, `compose.yaml`, `task dev`, graceful shutdown.
  3. Postgres and the first goose migration, run by a separate `hello-migrate` container.
  4. The Protobuf API (`hello.v1.GreetingService/GetGreeting`), Go code generated by buf, pgx reading the newest greeting.
  5. The React + TypeScript + Vite web app with Tailwind, TypeScript code generated by buf, and Vitest tests.
  6. Caddy as the only published entry point (http://localhost:8080).
  7. golangci-lint, Oxlint, Prettier and buf checks (`task lint`, `task format`), run before each commit by Lefthook.
  8. CI on GitHub Actions. The first run passed in 1m21s.
- Extra improvements asked for by the owner: a smaller goose image (Postgres driver only), faster health checks while starting, Compose Watch rebuilds for the Go service, and the Tailwind VS Code extension.
- The owner's own changes: a second migration, an `id` field in the API (reviewed in [docs/reviews/2026-10-31-review-greeting-id.md](../reviews/2026-10-31-review-greeting-id.md)), and a blue greeting number.

## Problems solved

- Newer versions than older tutorials show: connect-go v2 (plain messages, `connect.NewServer`), Postgres 18 (volume at `/var/lib/postgresql`), npm's install-script approvals (`fsevents` denied), Vite's starter using Oxlint.
- Protobuf field numbers: the owner's first `id` change reused field 1; `buf breaking` found it, and CI now checks it.
- The pre-commit hook didn't find the tools when git runs without the shell's setup; `.lefthookrc` puts mise's shims on the PATH.
- Mistakes by the agent, all fixed: deleted the owner's local greetings to test an empty table (restored right away); two broken hook tests (stash and zsh word splitting).
