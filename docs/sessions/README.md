# Sessions

A short summary of each working session with an agent. The next agent (or you, on another computer) reads the latest one to continue where the last session stopped.

Summaries record **decisions and reasons**, not full chat transcripts.

## How to add one

1. Copy `_template.md`.
2. Name it with the date and topic: `2026-11-02-hello-world-service.md`.
3. Fill it in at the end of the session.
