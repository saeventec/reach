# Decisions

Decision records (also called ADRs, "Architecture Decision Records"). Each file records one decision: what we chose, why, and which alternatives we considered.

Why keep them: months later, you (or an agent) can read *why* something is the way it is, instead of guessing.

## How to add one

1. Copy `_template.md`.
2. Name it with the next number and a short title: `0011-use-sqlc-for-queries.md`.
3. Fill it in. Keep it short.

Decisions can change. To change one, write a new record and set the old one's status to "Replaced by 00XX". Never delete old records: they are history.
